# racing

Игра гонки
В проекте реализована проверка на столкновения с другими объектами, логика отрисовки машин (чтобы они не рисовались друг на друге и между ними можно было проехать)
Также реализовано меню, окно паузы, окно окончания игры, счетчик, счетчик лучшего счета

Написано по принципам ООП

## Если клонировать проект в папку, не нужно переходить на уровень выше, так как все пути написаны в формате перехода в проект

Управление клавишами "a" и "d" (влево и вправо соответственно)
